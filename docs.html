EchoLike Lite · Install guide

← Back to download

1. Start your inbox

On your computer, download server.py and run it:

python3 server.py

It prints its address (for example http://192.168.0.5:8931). Keep that window open.

2. Load the extension

  1. Download the zip and unzip it into a folder you keep.
  2. Open chrome://extensions (Edge: edge://extensions, Brave: brave://extensions).
  3. Turn on Developer mode (top right), click Load unpacked, pick the folder.

Firefox: about:debugging#/runtime/this-firefox → Load Temporary Add-on → pick manifest.json inside the folder (Firefox removes it when it closes).

3. Connect

  1. Click the EchoLike icon and press Find my inbox. There is nothing to copy: the inbox on this computer issues the extension its own key.
  2. Inbox on another computer, or a hosted one? Open Advanced in the popup and type its address — it issues the key there too. A token is only needed when a hosted inbox handed you one.
  3. The popup says ✓ Connected. Like or bookmark any post on X — a green toast confirms it was sent.
  4. Open the inbox address in your browser to see everything captured.

Ads

Promoted posts and promoted trends are hidden on X. The switch is in the extension popup: untick Hide ads on X to see them again. Liking an ad still works and is still captured — it just arrives marked as an ad, never silently dropped.

Phones and automatic updates

The zip never updates itself: a folder has nowhere to look for a new version. If you want the Update button on your browser's extensions page to work, install the packaged build instead: echolike-lite.crx. It carries this page's address as its update source, so Update downloads and installs new versions for you.

Quetta (Android): open the .crx with the browser and confirm. If it answers CRX_REQUIRED_PROOF_MISSING, that browser no longer accepts packages from outside its store: use the zip and repeat steps 2–3 with each new zip.

Without an inbox

Captures are still saved in the browser: click the EchoLike icon and the popup lists the last 30 with a link to each post. Connect an inbox later — the waiting ones send when you press Save.

What it does with your likes

The extension reads the posts you like or bookmark (author, text, link) and sends them to the inbox address you connected. Without an inbox everything stays in this browser. There is no EchoLike account. Remove the extension and it stops.

Why Chrome shows a developer-mode warning

EchoLike Lite is not in the Chrome Web Store: the store asks for identity verification. The notice appears for every extension installed this way, it is not a virus alert, and you can close it. The whole source is public, with no build step and no minified code.

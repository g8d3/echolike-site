Extensión EchoLike

ExtensiónDirectorioFunding y alertasEnlaces

Gratis y de código abierto (MIT). Dale like o guarda en X y llega a EchoLike. Sin cuenta. Zip en Chrome o tienda de complementos de Firefox.

Versión: 2.7.0

Descargar el zipCódigo en GitHub

Instalar, paso a paso

  1. Descarga el zip y descomprímelo en una carpeta que vayas a conservar (no la borres después).
  2. Abre chrome://extensions (Edge: edge://extensions, Brave: brave://extensions).
  3. Activa el Modo desarrollador (interruptor arriba a la derecha).
  4. Pulsa Cargar descomprimida y elige la carpeta.
  5. Fija EchoLike desde el ícono de rompecabezas, abre su popup, pulsa Copiar código y envía /par más el código al bot.
  6. Abre o recarga x.com. Dale like o guarda un post: llega en segundos.

Sobre el aviso de Chrome

EchoLike no está en la Chrome Web Store a propósito (la tienda exige verificar identidad). Chrome puede mostrar “Inhabilitar extensiones en modo desarrollador”. Sale con cualquier extensión instalada así y no es una alerta de virus; ciérralo para conservar EchoLike. Todo el código es público, sin compilación ni código minificado.

Firefox (escritorio): about:debugging#/runtime/this-firefox → Cargar complemento temporal → elige manifest.json. Se quita al cerrar Firefox.

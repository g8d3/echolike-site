De dónde salen estos valores

Qué significa cada columna

  • Month: The calendar month the count covers, written out (for example May 2026). Fuente: puesto a mano.
  • New CVEs (count): How many CVEs were published that month, read from the total count in the NVD API. Fuente: la base de vulnerabilidades del NIST (NVD).
  • Notes: Our editorial notes about this entry. Fuente: nuestras notas editoriales.

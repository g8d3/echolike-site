How this data is built

ExtensionDirectoryFunding & alertsLinks

The rules every table in this directory follows. They are checked automatically on every build and by an independent AI reviewer before anything is published. When we get something wrong, the fix becomes a new rule here.

Column names and values are in English: the directory keeps one data standard, so a value means the same thing in every language version.

  1. Each column holds one fact: one value, or one list answering "which X" from a fixed vocabulary (for example which chat apps, which memory stores). No umbrella labels that mix several different things.
    Why: A mixed column can't be filtered, compared or checked; a fixed-vocabulary list still answers one question (which X).
    Added 2026-10-22, after: Coco: fixed-vocabulary lists are one fact
  2. Every value links to a source page that states it, or is calculated from other sourced values with the formula shown in words.
    Why: Readers must be able to check every cell themselves.
    Added 2026-10-22, after: Nova: hand-verify values with source URLs
  3. Never fill a cell with an assumption or estimate. Unknown stays empty and shows as a dash.
    Why: One invented number makes the whole table untrustworthy.
    Added 2026-10-22, after: Nova caught an invented 'typical monthly cost' of $60 for 7 harnesses
  4. Prices come only from the official pricing page, with the exact dollar amount, billing period, date checked and link.
    Why: Prices change and third-party summaries are often wrong.
    Added 2026-10-22, after: Nova caught invented pricing data
  5. Every number shows its unit, such as $/month, MB, hours or %.
    Why: A bare number like 20 means nothing without a unit.
    Added 2026-10-22, after: Nova: typed units in the data standard
  6. Columns with choices use a fixed list of values, each with a plain-English name. Never "varies" or "depends".
    Why: Vague words can't be filtered and hide missing research.
    Added 2026-10-22, after: Nova: closed vocabularies in the data standard
  7. A value checked by a person is never overwritten by AI. If AI disagrees, the disagreement goes to a review queue.
    Why: Automatic re-extraction had overwritten a hand-checked value (pi's model providers).
    Added 2026-10-22, after: Nova: mark each value as checked by a person or by AI
  8. Every column has a plain-English name and a one-sentence description, shown in the column list and when you hover or tap its header.
    Why: Readers can't use a column they don't understand.
    Added 2026-10-22, after: Nova: the 'Writes its own memory' column had no description
  9. No unexplained symbols. Calculated columns say "(calculated)" and explain the formula in words.
    Why: An unexplained mark confuses readers instead of informing them.
    Added 2026-10-22, after: Nova: an unexplained marker on calculated columns was confusing
  10. The page is in plain English. No internal code names (words joined with underscores) in headers, values or text.
    Why: Internal names joined with underscores mean nothing to readers.
    Added 2026-10-22, after: Nova: use human labels in headers, not code names
  11. Tables work on a phone (390 px wide). By default about 8 columns show, with column groups and a column chooser.
    Why: Most readers open links on their phone.
    Added 2026-10-22, after: Nova: short default column set with mobile-first group toggles
  12. Before calling work done, look at the published pages the way a reader would, on a phone and a desktop, not just at the code.
    Why: Code that runs can still produce pages that confuse.
    Added 2026-10-22, after: Nova: our work was careless (a missing description and an unexplained marker)
  13. An independent AI reviewer, using a different model from the one that built the page, reads it as a skeptical first-time reader. High-severity findings block publishing.
    Why: Reviews are done by AI models, not by Nova (EchoLike's founder), and by different models from the one that built the page.
    Added 2026-10-22, after: Nova: reviews must be done by models, not by him
  14. Every correction from Nova becomes a rule on this page, checked on every build from then on.
    Why: The same mistake should never come back.
    Added 2026-10-22, after: Nova: append every correction to the checklist

EchoLike extension

ExtensionDirectoryFunding & alertsLinks

Free and open source (MIT). Like or bookmark on X, it arrives in EchoLike. No account. Chrome zip or Firefox add-ons store.

Version: 2.7.0

Download the zipSource code on GitHub

Install, step by step

  1. Download the zip and unzip it into a folder you keep (do not delete it later).
  2. Open chrome://extensions (Edge: edge://extensions, Brave: brave://extensions).
  3. Turn on Developer mode (switch, top right).
  4. Click Load unpacked and choose the unzipped folder.
  5. Pin EchoLike from the puzzle icon, open its popup, press Copy code and send /par plus the code to the bot.
  6. Open or reload x.com. Like or bookmark a post: it arrives in seconds.

About the Chrome warning

EchoLike is not in the Chrome Web Store on purpose (the store requires identity verification). Chrome may show “Disable developer mode extensions”. It appears for every extension installed this way and is not a virus alert; close it to keep EchoLike. The full source is public, with no build step and no minified code.

Firefox (desktop): about:debugging#/runtime/this-firefox → Load Temporary Add-on → pick manifest.json. It is removed when Firefox closes.

Legend

Status

  • running: it is on right now
  • waiting: it starts on its own
  • done: its last run finished
  • failed: its last run did not finish
  • paused: it exists but it is switched off

Sources

  • systemd --user services and timers — what runs, its last start, its next run and the command line of every unit
  • the agent job queue — each queued job's own task file and the log that job writes, read by the queue scan
  • the private app — the private app's database: its task list and the run log of every job
  • Grok Bot routines — the ported copies of the routines Coco runs on its own servers, each with its schedule note
  • the script's own line — a script writes its own run line when it finishes, so the page shows what it did

Gratis, sin cuenta. Chrome, Edge, Brave y Firefox.

  1. Descomprime el zip. / Unzip the file.
  2. Chrome, Edge o Brave: abre chrome://extensions (o edge://extensions), activa Modo de desarrollador / Developer mode, elige Cargar descomprimida / Load unpacked y señala la carpeta que descomprimiste. / Do the same to load the unpacked folder.
  3. Firefox: abre about:debugging#/runtime/this-firefox, pulsa Cargar complemento temporal y elige el archivo manifest.json. / Load a temporary add-on and pick manifest.json.
  4. Abre x.com, dale like o guarda un post, y aparecerá en EchoLike. / Open x.com, like or bookmark a post, and it shows up in EchoLike.
